# ImagePlumber Chrome & Edge Extension

This lightweight Chrome Extension provides instant 1-click access to the ImagePlumber suite and acts as a high-authority (DA 95+) do-follow backlink generation asset when published on the **Chrome Web Store** and **Microsoft Edge Add-ons**.

---

## 🛠 How to Test Locally in Chrome / Edge

1. Open **Google Chrome** (or Microsoft Edge).
2. Navigate to `chrome://extensions` (or `edge://extensions`).
3. Enable **Developer mode** using the toggle in the top-right corner.
4. Click **Load unpacked**.
5. Select the `chrome-extension/` folder located at `c:\Projects\Image Craft\chrome-extension`.
6. The ImagePlumber extension icon will now appear in your browser toolbar!

---

## 🚀 How to Publish to the Chrome Web Store

1. Zip the contents of the `chrome-extension/` folder into `imageplumber-extension.zip`.
2. Go to the [Chrome Web Store Developer Dashboard](https://chrome.google.com/webstore/devconsole).
3. Click **New Item** and upload `imageplumber-extension.zip`.
4. Fill in the store listing:
   - **Title**: `ImagePlumber - 100% Private Local Image Tools`
   - **Category**: `Productivity` / `Photos`
   - **Website URL**: `https://imageplumber.com` *(This provides the official authority link back to your domain)*
   - **Summary**: `100% client-side privacy-first image tools suite in your browser. Compress photos, remove backgrounds with AI, sign PDFs with zero cloud uploads.`
5. Submit for review (approval usually takes 24–48 hours).
